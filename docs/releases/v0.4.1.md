## Codex Usage Supervisor 0.4.1

Temporary account refresh failures now retain the newest allowance snapshot instead of reverting immediately to older local session metadata.

### Changes

- Persist successful account snapshots in a separate network cache that survives service restarts.
- Select the newest observation across live account data, the network cache, and local Codex session data.
- Preserve the original observation timestamp when reading cached data; newer local data can still win.
- Distinguish saved network data from local session data in GNOME and Windows.
- Ignore missing or corrupt caches and keep live results usable if a cache write fails.

### Linux installation

Download `codex-usage-supervisor_0.4.1_all.deb`, then run:

```bash
sudo apt install ./codex-usage-supervisor_0.4.1_all.deb
systemctl --user daemon-reload
systemctl --user restart codex-usage-supervisor.service
```

On X11, press **Alt+F2**, type **r**, and press **Enter** to reload GNOME Shell. On Wayland, log out and sign in again. Enable the extension if necessary:

```bash
gnome-extensions enable codex-usage-supervisor@owen.local
```

The Linux package targets Ubuntu 22.04 / GNOME Shell 42. Its architecture is `all` because the backend and extension contain no native compiled binaries.
