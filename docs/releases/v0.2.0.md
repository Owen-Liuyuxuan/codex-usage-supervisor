## Codex Usage Supervisor 0.2.0

The first packaged GNOME Shell release of Codex Usage Supervisor.

### Highlights

- GNOME Shell 42 top-panel indicator showing current Codex allowance usage.
- Modern popover with 5-hour and 7-day windows, reset countdowns, daily
  activity, and recent tasks.
- Local-only Python D-Bus service; the Shell extension never parses session
  files directly.
- Native GTK4 and Libadwaita preferences.
- Debian package for Ubuntu 22.04.

### Install

Download `codex-usage-supervisor_0.2.0_all.deb`, then run:

```bash
sudo apt install ./codex-usage-supervisor_0.2.0_all.deb
```

Restart GNOME Shell so it discovers the new extension. On X11, press
`Alt+F2`, enter `r`, and press Enter. On Wayland, log out and sign in again.
Then enable the addon:

```bash
gnome-extensions enable codex-usage-supervisor@owen.local
```

The application-menu entry opens preferences. The live dashboard is the
`Codex <percent>%` indicator in the upper-right GNOME panel.
